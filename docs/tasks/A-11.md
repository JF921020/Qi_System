# A-11：左下帳號與管理導覽

完成日期：2026-10-08 00:10（Asia/Taipei）。狀態：實作及本機驗證完成，未部署。

## 需求與完成內容

- 計算首頁與 IC 管理頁共用左下帳號選單，彈出視窗只顯示「IC 管理」及「帳號設定」兩個入口。
- 「IC 管理」前往 `/ics/` 後預設跳轉至 RX IC 列表（`/ics/rx/`），由左側工具欄切換 RX IC 或 Charger IC，沿用主介面導覽樣式並醒目標示目前類型；列表、匯入與編輯頁皆可切換。「帳號設定」前往 `/accounts/settings/`，顯示登入狀態、登入／登出及依權限提供帳號管理入口。
- 顯示目前帳號及角色；帳號設定頁只有 superuser 顯示帳號管理入口。訪客仍可瀏覽 IC，變更資料沿用既有登入、staff 權限與 CSRF 保護。
- 使用原生 details／summary：Enter 或空白鍵展開，Tab 移動至連結，Escape 關閉並將焦點還給觸發按鈕，點擊外部關閉。
- 桌面選單向上展開；760px 以下管理頁改為直向導覽，選單在文件流中展開，可捲動操作。

## 使用方式

點選左下帳號名稱，再選擇「IC 管理」或「帳號設定」進入對應頁面。IC 管理頁區分 RX／Charger；帳號設定頁提供登入與登出。管理者登入後可沿用原有匯入／編輯功能；登出以含 CSRF token 的 POST 表單執行。
